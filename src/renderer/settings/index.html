Receipt Configuration
Card Terminal

The VP100 connects to this computer. In the Valor Portal (Device Management → EPI → Edit Parameter → Valor Connect) set Connection Type = TCP, point it at the IP + port below, then do a Param Download on the terminal.

Receipt Printer

Windows: use "printer" for the default printer, or the exact printer name. If offline, receipt is saved as a .txt file.

Cash Drawer

Pops automatically when the cashier presses Cash. A standalone USB drawer (e.g. Clover D100) connects as a serial/COM port — pick it below. A drawer wired into the receipt printer uses "Through receipt printer" instead.

If the drawer doesn't pop with 1B 70 00 19 FA, try 1B 70 01 19 FA (pin 5), 1B 70 00 40 50, or 07, then Test.

Zebra Barcode Printer

For printing 2.25" × 1.25" barcode tags from Inventory and Invoices. Connect via TCP/IP (Zebra Z8, Z11, ZD220, GK420d, etc.).
