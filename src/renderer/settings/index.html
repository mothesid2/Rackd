Card Terminal

Valor Connect semi-integration: the terminal is the server and the POS connects to it. On the VP100 — Portal → Device Management → EPI → Edit Parameter → Terminal & Transaction → Valor Connect → enable TCP or WebSocket (match the selector below) → Param Download; it shows "Server is Waiting for Transaction". Then enter the terminal's IP and port here.

Receipt Printer

Pick your installed receipt printer (e.g. Star TSP143). Install the printer's driver first, then click Refresh. Works the same on Windows and Mac. If the printer is off, receipts save as a .txt file.

Cash Drawer

Pops automatically when the cashier presses Cash. A standalone USB drawer (e.g. Clover D100) connects as a serial/COM port — pick it below. A drawer wired into the receipt printer uses "Through receipt printer" instead.

Default starting cash assumed for a new shift on THIS register. A cashier can correct the actual count for a single shift from the Cash Drawer panel on the POS screen without changing this default.

If the drawer doesn't pop with 1B 70 00 19 FA, try 1B 70 01 19 FA (pin 5), 1B 70 00 40 50, or 07, then Test.

Zebra Barcode Printer

For printing 2.25" × 1.25" barcode tags from Inventory and Invoices. Connect via TCP/IP (Zebra Z8, Z11, ZD220, GK420d, etc.).
